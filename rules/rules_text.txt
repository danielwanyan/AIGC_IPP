# 货不对板（IPP）判定规则
# Inconsistent Product Presentation (IPP) Detection Rules

## 版本信息

- 当前版本：2026-06-23-v8
- 上次更新：2026-06-23
- 更新内容：新增 FP-11（商品未物理出镜豁免）防误判规则，明确有讲品但商品未以实物形式物理展示（仅屏幕/截图/口头）不算 IPP，更新判定流程和示例

## 规则索引

| 编号 | 规则名称 | 说明 |
|------|---------|------|
| IPP01 | 货不对板 | 视频中展示的商品与挂车商品图片不一致 |

---

## 适用范围

本规则适用于 **EU 地区所有内容**（AIGC + 非AIGC）。

**重要说明**：
- `aigc_video_id` 为外部权威打标，仅用于区分问题类型（AIGC货不对板 / 非AIGC货不对板）
- `aigc_video_id` **不是跳过条件**，所有内容都需要分析
- 本规则针对 EU 地区，ASR/OCR 为外语（英语等）

## 输入信息

### 图像信息

| 字段 | 说明 |
|------|------|
| 视频帧 | 5张基于视频时长等分抓取的关键帧 |
| 挂车商品全量图片 | 视频绑定的商品所有图片（JSON 数组字符串格式，每个视频可能有多个商品图） |

**重要说明**：
- `Product_image` 是 JSON 数组字符串格式，例如：`["url1", "url2", "url3"]`
- 包含该商品的所有图片（主图、细节图、不同颜色/款式图等）
- 商品一致性判断时，**只要视频帧中的商品与任意一张商品图片一致，就算一致**

### 文本信息

| 字段 | 说明 |
|------|------|
| ASR | 视频语音转文本（EU地区为外语） |
| OCR | 视频画面中识别出的文字（EU地区为外语） |
| product_category | 挂车商品的三级类目名称（可能是当地语言） |

### 外部数据打标（权威数据，必须完全信任）

| 字段 | 说明 |
|------|------|
| `aigc_video_id` | AIGC 判定标签，仅用于区分问题类型 |
| `product_category` | 挂车商品的三级类目名称，**仅用于豁免判断** |

**aigc_video_id 说明**：
- `aigc_video_id` 为 `null` → 非AIGC内容（非AIGC货不对板）
- `aigc_video_id` 有值（数字）→ AIGC内容（AIGC货不对板）
- **所有内容都需要分析，不会跳过**

**product_category 重要说明**：
- `product_category` **仅用于豁免判断**（判断是否属于盲盒/首饰/玉石/卡牌/服饰类目）
- `product_category` **绝对不能**用于判定商品是否一致
- 商品一致性判断**必须只基于图片对比**（视频帧商品 vs 挂车商品全量图片）
- 如果 `product_category` 与挂车商品图片显示的商品不一致，**以挂车商品图片为准**判断商品类型
- 禁止因为 `product_category` 元数据与图片显示的商品不一致而判定为 IPP（见 FP-10）

**商品图片对比重要说明**：
- 挂车商品可能有**多张图片**（不同角度、不同颜色、不同款式）
- 商品一致性判断时，**只要视频帧中的商品与任意一张商品图片一致，就算一致**
- 即使视频帧展示的是某张特定图片的颜色/款式，只要该颜色/款式在全量图片中存在，就不算 IPP

## 判定流程

```
Step 1: 检查是否有商品推广（ASR/OCR）
    ├─ 无推广 → 不命中（no_hit）
    └─ 有推广 → Step 2

Step 2: 商品对比（视频帧商品 vs 挂车商品全量图片）
    ├─ 首先检查：视频帧中是否有挂车商品的物理实物展示？
    │   ├─ 无物理展示（仅屏幕/截图/口头）→ 不命中（no_hit，FP-11）
    │   └─ 有物理展示 → 继续对比
    ├─ 视频帧商品与任意一张商品图片一致 → 不命中（no_hit）
    └─ 视频帧商品与所有商品图片都不一致 → Step 3

Step 3: 豁免检查
    ├─ 挂车商品属于盲盒/首饰/玉石/卡牌类目？
    │   └─ 是 → 检查视频帧商品与挂车商品是否同三级类目
    │       ├─ 同三级类目 → 豁免（no_hit）
    │       └─ 不同三级类目 → 命中（hit）
    ├─ 挂车商品属于服饰（上下装，不含鞋帽）类目？
    │   └─ 是 → 检查是否为同SPU不同SKU（仅颜色/花纹差异）
    │       ├─ 是 → 豁免（no_hit）
    │       └─ 否 → 命中（hit）
    └─ 其他类目 → 命中（hit）
```

**Step 2 详细说明**：
- 挂车商品可能有 N 张图片（不同角度、颜色、款式）
- 遍历所有商品图片，只要视频帧中的商品与**任意一张**图片在视觉上一致 → 判定为一致（no_hit）
- 只有当视频帧中的商品与**所有**商品图片都不一致时 → 才进入豁免检查

## 推广判定标准

ASR 或 OCR 中存在以下任意一种情况，即视为"有商品推广"：

| 推广类型 | 说明 | 英文关键词示例 |
|----------|------|---------------|
| 购买引导 | 引导用户点击购物车、下单、购买 | buy now, order now, shop now, add to cart, click cart, purchase |
| 价格信息 | 提及商品价格、优惠 | price, $, €, £, cost, only, just, special price |
| 促销信息 | 提及促销活动 | discount, sale, promotion, limited time, special offer, buy one get one |
| 商品介绍 | 介绍商品功能、特点 | this product, it has, features, made of, material |

**判定逻辑**：ASR 或 OCR 中存在上述任意类型内容 → 视为有推广

## 商品一致性判定标准

### 一致（不命中）

视频帧中出现的商品与**任意一张挂车商品图片**在以下方面一致：
- 商品类型（如都是口红、都是T恤）
- 商品款式、形状
- 商品颜色、花纹（服饰类除外，见豁免规则）
- 商品材质外观

**重要**：只要视频帧商品与**任意一张**商品图片一致 → 判定为一致（no_hit）

### 不一致（命中，除非豁免）

视频帧中出现的商品与**所有挂车商品图片**都存在明显差异：
- 完全不同的商品类型（如挂车是口红，视频展示的是眼影）
- 同款但不同款式（如挂车是圆领T恤，视频展示的是V领T恤）
- 明显不同的设计元素

**重要**：只有当视频帧商品与**所有**商品图片都不一致时 → 才判定为不一致（进入豁免检查）

---

## 防误判规则（重要！必须遵守）
## Anti-False-Positive Rules (IMPORTANT!)

**核心原则**：只有当视频帧中的商品与**所有挂车商品图片**都存在**实质性、根本性的差异**时，才判定为不一致。以下情况**不得**判定为不一致：

### 规则 FP-01：光线/色差差异
### Rule FP-01: Lighting and Color Differences

**问题场景**：挂车商品图片（其中一张）通常是专业影棚拍摄（打光均匀、色彩饱和），而视频帧可能是自然光、室内光或不同色温下拍摄，导致颜色看起来有差异。

**判定规则**：
- ✅ **忽略**单纯的光线明暗、色温、饱和度差异
- ✅ **忽略**影棚照片 vs 真实视频的色彩偏差
- ❌ 只有当颜色属于**完全不同的色系**（如红色 vs 蓝色）时，才考虑颜色差异
- ❌ 同色系深浅差异（如深红 vs 浅红）**不得**作为不一致依据

**示例**：
- 挂车商品图片（其中一张）：影棚拍摄的鲜红色口红
- 视频帧：自然光下拍摄的同款口红，颜色看起来偏暗偏深
- **判定**：一致（no_hit），光线差异不构成不一致

---

### 规则 FP-02：品牌名称/OCR文字不对比
### Rule FP-02: Do NOT Compare Brand Names or OCR Text

**问题场景**：挂车商品图片（其中一张）上的品牌文字可能是镜像/反转的（用于直播场景），OCR识别会出错；视频帧中的文字可能模糊、角度倾斜。

**判定规则**：
- ✅ **禁止**对比品牌名称、Logo文字、产品型号文字
- ✅ **禁止**依赖OCR识别的文字进行商品对比
- ✅ 只对比商品的**视觉外观特征**（形状、款式、颜色色系、材质纹理）
- ❌ 不得因文字识别差异（如"NIKE" vs "EKIN"镜像）判定不一致

**示例**：
- 挂车商品图片（其中一张）：品牌文字是反转的（镜像显示）
- 视频帧：品牌文字是正常显示的
- **判定**：一致（no_hit），文字方向差异不构成不一致

---

### 规则 FP-03：设计效果图 vs 实物差异
### Rule FP-03: Design Renders vs Real Products

**问题场景**：挂车商品图片（其中一张）可能是3D渲染图、设计效果图，带有特殊光影效果、滤镜效果，而视频帧展示的是真实产品。

**判定规则**：
- ✅ **忽略**渲染图的特殊视觉效果（发光、光晕、夸张光影）
- ✅ 只对比**核心设计元素**（形状、结构、款式、图案）
- ✅ 理解效果图与实物的正常差异
- ❌ 不得因渲染效果 vs 实物的视觉差异判定不一致

**示例**：
- 挂车商品图片（其中一张）：3D渲染的手表，带有夸张的发光效果
- 视频帧：真实手表，没有发光效果
- **判定**：一致（no_hit），渲染效果差异不构成不一致

---

### 规则 FP-04：仅基于给定全量图片对比，不假设其他变体
### Rule FP-04: Compare Only With Given All Images, Do NOT Assume Variants

**问题场景**：系统提供挂车商品的**全量图片**（包含不同角度、颜色、款式的多张图片），但可能仍有其他颜色/款式变体未被包含在给定图片中。

**判定规则**：
- ✅ 只与**给定的全量挂车商品图片**进行对比
- ✅ 只要视频帧中的商品与**任意一张**给定图片一致 → 判定为一致（no_hit）
- ✅ 如果视频帧中的商品与**所有**给定图片**款式一致但颜色不同**，按正常规则判断（服饰类豁免，其他类目需判断）
- ✅ 理解"只给了这些图片"的限制，不要假设"应该有其他颜色/款式"
- ❌ 不得因"视频中展示了其他颜色变体"而判定不一致（除非款式也不同，且该款式不在给定图片中）

**关键区分**：
| 情况 | 服饰类 | 其他类目 |
|------|--------|---------|
| 视频帧商品与任意一张图片款式颜色都一致 | 一致（no_hit） | 一致（no_hit） |
| 款式一致，颜色不同（该颜色不在图片中） | 豁免（no_hit） | 需判断是否同SPU |
| 款式不同（该款式不在图片中） | 命中（hit） | 命中（hit） |

---

### 规则 FP-05：服饰类特殊判断标准
### Rule FP-05: Apparel Special Judgment Criteria

**问题场景**：服饰穿着方式不同会导致视觉差异（如裤子塞进靴子、袖子挽起、衣服扎进裤子）。

**判定规则**：
- ✅ **忽略**穿着方式导致的视觉差异：
  - 裤子塞进靴子 ≠ 短裤
  - 长袖挽起 ≠ 短袖
  - 衣服扎进裤子 ≠ 短款上衣
  - 外套敞开 vs 扣上 ≠ 不同款式
- ✅ 重点对比**核心款式特征**：
  - 领口形状（圆领/V领/翻领）
  - 衣长类型（长款/短款）
  - 版型（修身/宽松）
  - 图案设计
- ✅ 同款式不同颜色 → 豁免（同SPU不同SKU）
- ❌ 不得因穿着方式差异判定不一致

**示例**：
- 挂车商品图片（其中一张）：黑色长裤（平铺展示）
- 视频帧：模特穿着同款黑色长裤，但裤脚塞进靴子里，看起来像短裤
- **判定**：一致（no_hit），穿着方式差异不构成不一致

---

### 规则 FP-06：多商品/配件场景判断
### Rule FP-06: Multiple Products / Accessories Scenarios

**问题场景**：视频帧中可能同时展示多个商品，或者商品带有配件（如手机带壳、包包挂饰）。

**判定规则**：
- ✅ 如果视频帧中**出现了挂车商品**（即使同时有其他商品），只要挂车商品本身与**任意一张商品图片**一致 → 不命中
- ✅ **忽略**商品附带的配件（手机壳、挂饰、表带等），只对比商品本身
- ✅ 如果视频帧中**完全没有出现挂车商品**，而展示了其他商品 → 才需要判断是否不一致
- ✅ 型号数字差异（如"iPhone 15" vs "iPhone 15 Pro"）需要看**外观差异**，如果外观与任意一张商品图片一致则不命中
- ❌ 不得因"视频中还展示了其他商品"而判定不一致（只要挂车商品也出现了且与任意一张图片一致）

**判断流程**：
```
视频帧中是否出现了挂车商品？
    ├─ 是 → 对比该商品与任意一张商品图片是否一致
    │   ├─ 一致 → no_hit
    │   └─ 不一致 → 进入豁免检查
    └─ 否 → 视频中展示的是什么商品？
        ├─ 完全不同类目 → hit（category）
        └─ 同类目不同款式 → hit（appearance）
```

### 规则 FP-07：语言/文字内容不对比
### Rule FP-07: Do NOT Compare Language/Text Content

**问题场景**：商品包装上的文字可能因地区版本不同而有不同语言，但产品本身是一样的。

**判定规则**：
- ✅ **忽略**包装上的文字语言差异
- ✅ 只对比**产品本身的视觉外观**
- ❌ 不得因包装文字语言不同判定不一致

---

### 规则 FP-08：纯颜色差异豁免（全类目适用）
### Rule FP-08: Pure Color Difference Exemption (All Categories)

**问题场景**：视频帧中的商品与**任意一张挂车商品图片**在功能、款式、结构上完全一致，仅颜色不同。这种情况属于同SPU不同SKU，不应判定为货不对板。

**判定规则**：
- ✅ 如果商品的**功能、款式、结构、形状完全一致**，仅颜色不同 → **豁免（no_hit）**
- ✅ 此规则**适用于所有类目**（不限于服饰类）
- ✅ 重点对比核心功能特征：结构设计、部件组成、功能布局、款式造型
- ❌ 只有当颜色差异伴随款式/结构差异时，才考虑判定不一致

**判断标准**：

| 对比维度 | 一致 | 不一致 |
|---------|------|--------|
| 功能设计 | ✅ 相同 | ❌ 不同 |
| 结构形状 | ✅ 相同 | ❌ 不同 |
| 部件组成 | ✅ 相同 | ❌ 不同 |
| 款式造型 | ✅ 相同 | ❌ 不同 |
| 颜色 | ❌ 不同 | ❌ 不同 |
| **结果** | **豁免（no_hit）** | **需进一步判断** |

**示例**：
- 挂车商品图片（其中一张）：白色化妆桌（带LED灯镜、左右各3个抽屉、中间2个抽屉）
- 视频帧：黑色同款化妆桌（结构、抽屉数量、LED灯镜完全一致，仅颜色不同）
- **判定**：一致（no_hit），纯颜色差异豁免（FP-08）

---

### 规则 FP-09：小物件/装饰品忽略
### Rule FP-09: Ignore Small Objects and Decorations

**问题场景**：视频帧中商品周围或上面摆放了小物件、装饰品（如化妆品、护肤品、花瓶、绿植、书籍、闹钟等），这些不是商品本身的一部分，不能用来判断商品是否一致。

**判定规则**：
- ✅ **忽略**商品上/周围摆放的所有小物件和装饰品
- ✅ **只对比商品本身的核心结构和外观**
- ✅ 小物件包括但不限于：化妆品、护肤品、香水、花瓶、绿植、书籍、闹钟、灯具、摆件等
- ❌ 不得因视频帧中摆放的小物件不同而判定商品不一致

**判断方法**：
1. 首先识别**商品本身的边界**（如化妆桌的桌体、抽屉、镜子部分）
2. **剥离**所有摆放在商品上/周围的非商品本身物品
3. 只对比**剥离后剩余的商品主体**

**示例**（对应你提供的化妆桌图片）：
- 挂车商品图片（其中一张）：白色化妆桌，桌面上摆放了香薰、花瓶、化妆品等装饰
- 视频帧：同款白色化妆桌，桌面上摆放了不同的化妆品、护肤品等装饰
- **判定**：一致（no_hit），小物件/装饰品忽略（FP-09），化妆桌本身结构完全相同

---

### 规则 FP-10：product_category 元数据仅用于豁免判断
### Rule FP-10: product_category Metadata Only for Exemption Judgment

**问题场景**：`product_category` 元数据可能存在标注错误（如实际是梳子但 category 写的是洗发水），如果基于元数据与图片不一致判定为 IPP，会造成严重误伤。

**判定规则**：
- ✅ `product_category` **仅用于豁免判断**（判断是否属于盲盒/首饰/玉石/卡牌/服饰类目）
- ✅ 商品一致性判断**必须只基于图片对比**（视频帧商品 vs 挂车商品全量图片）
- ✅ 如果 `product_category` 与挂车商品图片显示的商品不一致，**以挂车商品图片为准**判断商品类型
- ❌ **绝对禁止**因为 `product_category` 元数据与图片显示的商品不一致而判定为 IPP
- ❌ **绝对禁止**将 `product_category` 作为判断商品类型的依据（豁免判断除外）

**判断流程**：
```
商品一致性判断：
    对比视频帧商品 vs 任意一张挂车商品图片（图片对比）
        ├─ 一致 → no_hit
        └─ 不一致 → 进入豁免检查

豁免检查时才使用 product_category：
    判断 product_category 的语义是否属于豁免类目（盲盒/首饰/玉石/卡牌/服饰）
        ├─ 是 → 应用对应豁免规则
        └─ 否 → 按普通类目处理

如果 product_category 与挂车商品图片不一致：
    → 以挂车商品图片为准判断商品类型
    → product_category 仍可用于豁免判断（如果语义上属于豁免类目）
    → 绝对不能因为 category 与图片不一致就判定 hit
```

**示例**（梳子案例）：
- 挂车商品图片（其中一张）：加热造型梳（hot brush）
- 视频帧：同款加热造型梳
- `product_category`："Shampoo & Conditioner"（洗发水护发素，标注错误）
- **判定**：一致（no_hit），视频帧商品与任意一张挂车商品图片视觉上完全一致。`product_category` 标注错误不影响商品一致性判断（FP-10）。

---

### 规则 FP-11：商品未物理出镜豁免
### Rule FP-11: Product Not Physically Shown Exemption

**问题场景**：ASR/OCR 有商品推广内容，但视频帧中挂车商品仅出现在手机屏幕、电脑截图中，或仅口头提及，商品本身没有以实物形式物理出镜。这种情况不属于"货不对板"，因为根本没有展示商品可供对比。

**判定规则**：
- ✅ 如果 ASR/OCR 有推广，但视频帧中**未出现挂车商品的物理实物展示** → **豁免（no_hit）**
- ✅ 物理实物展示定义：商品以真实实物形式出现在视频中（手持、摆放、穿戴等）
- ❌ 以下情况**不属于**物理实物展示：
  - 商品仅出现在手机屏幕、电脑屏幕、电视屏幕等电子屏幕中
  - 商品仅出现在截图、图片展示中
  - 仅口头提及商品，没有任何视觉展示
- ❌ 如果视频帧中出现了**其他商品的物理展示**（与挂车商品不同）→ 仍需判断是否不一致（不适用 FP-11）

**判断流程**：
```
ASR/OCR 有推广？
    ├─ 否 → no_hit
    └─ 是 → 视频帧中是否有挂车商品的物理实物展示？
        ├─ 无（仅屏幕/截图/口头）→ no_hit（FP-11）
        └─ 有 → 对比该实物与挂车商品图片
            ├─ 一致 → no_hit
            └─ 不一致 → 进入豁免检查
```

**示例**：
- 挂车商品：淋巴排毒补充剂（瓶装）
- ASR："Buy this lymphatic drainage supplement!"
- 视频帧：主播讲解 + 医疗解剖动画，没有出现任何补充剂瓶子/包装
- **判定**：no_hit（FP-11），商品未物理出镜，无法对比是否一致

## 豁免规则

### 重要说明：product_category 多语言语义理解与作用边界

`product_category` 可能是任何语言（英语、日语、韩语、西班牙语等），必须基于**语义理解**判断类目类型，而不是依赖特定语言的关键词。

**关键提醒**：
- `product_category` **仅用于豁免判断**，不能用于判定商品是否一致
- 商品一致性判断**必须只基于图片对比**（视频帧商品 vs 挂车商品全量图片）
- 如果 `product_category` 与挂车商品图片显示的商品不一致，**以挂车商品图片为准**
- 详见防误判规则 FP-10

**示例**：
- 日语"香水"、韩语"향수"、英语"Perfume" → 语义相同，属于同一类目
- 日语"美容・パーソナルケア" → 语义为"Beauty & Personal Care"

**判断方法**：
1. 理解 `product_category` 的语义含义（无论什么语言）
2. 判断该语义属于哪个类目类型（盲盒/首饰/玉石/卡牌/服饰/普通）
3. 基于语义进行豁免判断

---

### 豁免类型 1：盲盒、首饰、玉石、卡牌
### Exemption Type 1: Blind Boxes, Jewelry, Jade, Collectible Cards

**条件**：挂车商品的 `product_category` 语义上属于以下类目类型之一：

| 类目类型 | 语义说明 | 多语言示例 |
|----------|---------|-----------|
| 盲盒 | 盲盒、神秘盒子、惊喜盒子 | Blind Boxes, Mystery Boxes, ブラインドボックス, 블라인드 박스 |
| 首饰 | 珠宝、时尚配饰、项链、耳环、手链、戒指 | Jewelry, Necklaces, Earrings, ジュエリー, 액세서리 |
| 玉石 | 玉石、宝石、水晶 | Jade, Gemstones, Crystals, 宝石, 보석 |
| 卡牌 | 收藏卡、交易卡、游戏卡、体育卡 | Collectible Cards, Trading Cards, カード, 카드 |

**豁免规则**：
- 视频帧中展示的商品与**任意一张挂车商品图片**属于**同一个三级类目** → 豁免（不命中）
- 视频帧中展示的商品与**所有挂车商品图片**都**不属于同一个三级类目** → 命中

---

### 豁免类型 2：服饰（上下装，不含鞋帽）
### Exemption Type 2: Apparel (Tops & Bottoms, excluding Shoes & Hats)

**条件**：挂车商品的 `product_category` 语义上属于服饰类（上下装）

| 类目类型 | 语义说明 | 多语言示例 |
|----------|---------|-----------|
| 上衣 | T恤、衬衫、上衣、毛衣、卫衣、外套 | T-Shirts, Shirts, Tops, Sweaters, Hoodies, Tシャツ, 티셔츠 |
| 下装 | 裤子、牛仔裤、短裤、裙子、连衣裙、打底裤 | Pants, Jeans, Shorts, Skirts, Dresses, ズボン, 바지 |

**不适用此豁免**（语义判断）：
- 鞋类（Shoes, Footwear, 靴, 신발）
- 帽类（Hats, Caps, 帽子, 모자）
- 包类（Bags, Handbags, バッグ, 가방）

**豁免规则**：
- 视频帧中展示的商品与**任意一张挂车商品图片**是**同SPU不同SKU**（仅颜色/花纹差异）→ 豁免（不命中）
- 视频帧中展示的商品与**所有挂车商品图片****款式/形状都不同** → 命中

**判断标准**：

| 情况 | 结果 | 说明 |
|------|------|------|
| 同款不同颜色 | 豁免 | 同SPU不同SKU |
| 同款不同花纹 | 豁免 | 同SPU不同SKU |
| 不同款式（如圆领 vs V领） | 命中 | 不是同SPU |
| 不同类型（如T恤 vs 衬衫） | 命中 | 完全不同商品 |

---

### 豁免类型 3：纯颜色差异（全类目适用）
### Exemption Type 3: Pure Color Difference (All Categories)

**条件**：视频帧中的商品与**任意一张挂车商品图片**在**功能、款式、结构、形状上完全一致**，仅颜色不同。

**适用范围**：**所有类目**（不限于服饰类）

**判定规则**：
- 商品的**核心功能特征完全一致**（结构设计、部件组成、功能布局、款式造型）
- **仅颜色不同** → 豁免（no_hit）
- 颜色差异伴随款式/结构差异 → 不豁免

**判断标准**：

| 对比维度 | 要求 |
|---------|------|
| 功能设计 | 必须完全相同 |
| 结构形状 | 必须完全相同 |
| 部件组成 | 必须完全相同 |
| 款式造型 | 必须完全相同 |
| 颜色 | 可以不同 |

**示例**：
- 挂车商品主图：白色化妆桌（带LED灯镜、左右各3个抽屉、中间2个抽屉）
- 视频帧：黑色同款化妆桌（结构、抽屉数量、LED灯镜完全一致，仅颜色不同）
- **判定**：豁免（no_hit），纯颜色差异豁免

---

## 判定逻辑总结

| 情况 | 结果 | 说明 |
|------|------|------|
| 无商品推广 | no_hit | 没有推广行为，不构成货不对板 |
| 有推广 + 视频帧商品与任意一张商品图片一致 | no_hit | 展示商品与挂车商品一致（图片对比为准，FP-10） |
| 有推广 + 商品一致 + product_category 与图片不一致 | no_hit | 以图片为准，category 标注错误不构成 IPP（FP-10） |
| 有推广 + 商品不一致 + 盲盒/首饰/玉石/卡牌 + 同三级类目 | no_hit（豁免） | 特殊类目豁免 |
| 有推广 + 商品不一致 + 服饰 + 同SPU不同SKU | no_hit（豁免） | 服饰类目豁免 |
| 有推广 + 商品不一致 + 全类目 + 仅颜色不同（功能款式结构一致） | no_hit（豁免） | 纯颜色差异豁免（FP-08） |
| 有推广 + 商品未物理出镜（仅屏幕/截图/口头） | no_hit | 商品未物理展示，无法对比（FP-11） |
| 有推广 + 视频帧商品与所有商品图片都不一致 + 无豁免 | hit | 货不对板 |

## 输出格式

结构化JSON输出：

```json
{
  "decision": "hit|no_hit",
  "issue_type": "AIGC_IPP|non-AIGC_IPP",
  "inconsistency_type": "appearance|category|null",
  "exemption_check": {
    "category_type": "normal|blind_box|jewelry|jade|card|apparel",
    "is_exempted": true|false,
    "exemption_reason": "Same L3 category exemption|Same SPU different SKU exemption|Pure color difference exemption|Product not physically shown exemption|null"
  },
  "reason": "判定理由（英文）",
  "frames_analyzed": [1, 2, 3, 4, 5],
  "frames_with_product": [2, 3, 4]
}
```

### 输入字段说明（重要！）

| 字段 | 说明 |
|------|------|
| Product_image | 挂车商品全量图片（JSON 数组字符串格式），例如：`["url1", "url2", "url3"]`。包含该商品的所有图片（主图、细节图、不同颜色/款式图等）。商品一致性判断时，**只要视频帧中的商品与任意一张商品图片一致，就算一致**。 |

### 字段说明

| 字段 | 说明 |
|------|------|
| decision | 判定结果：hit=命中；no_hit=不命中 |
| issue_type | 问题类型：AIGC_IPP（aigc_video_id有值）；non-AIGC_IPP（aigc_video_id为null） |
| inconsistency_type | 不一致类型：appearance=外观不一致；category=类目不一致；null=一致 |
| exemption_check.category_type | 挂车商品类目类型：normal=普通；blind_box=盲盒；jewelry=首饰；jade=玉石；card=卡牌；apparel=服饰 |
| exemption_check.is_exempted | 是否豁免：true=豁免；false=不豁免 |
| exemption_check.exemption_reason | 豁免理由（英文） |
| reason | 判定理由说明（英文） |
| frames_analyzed | 分析过的视频帧编号（全部5帧） |
| frames_with_product | 出现商品展示的视频帧编号 |

### issue_type 判断逻辑

| aigc_video_id 值 | issue_type | 说明 |
|-----------------|------------|------|
| null | non-AIGC_IPP | 非AIGC内容的货不对板 |
| 有值（数字） | AIGC_IPP | AIGC内容的货不对板 |
