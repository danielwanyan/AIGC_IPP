# AIGC 挂车商品与讲解商品不一致（货不对板）判定规则
# AIGC Inconsistent Product Presentation (IPP) Detection Rules

## 版本信息

- 当前版本：2026-05-26-v1
- 上次更新：2026-05-26
- 更新内容：初始版本，AIGC货不对板检测规则

---

## 规则索引

| 编号 | 规则名称 | 说明 |
|------|---------|------|
| IPP01 | AIGC货不对板 | AIGC视频中展示的商品与挂车商品主图不一致 |

---

## 适用范围

本规则适用于 **EU 地区 AIGC 内容**。

根据 `is_aigc` 外部字段判断：
- `is_aigc` 为 `null` → 非AIGC内容，**跳过**（不适用此规则）
- `is_aigc` 有值（数字）→ AIGC内容，**进入分析**

**重要说明**：
- `is_aigc` 为外部权威打标，系统完全信任，不自行判断是否为AIGC
- 本规则针对 EU 地区，ASR/OCR 为外语（英语等），`product_category` 为英文三级类目名称

---

## 输入信息

### 图像信息

| 字段 | 说明 |
|------|------|
| 视频帧 | 5张基于视频时长等分抓取的关键帧 |
| 挂车商品主图 | 视频绑定的商品主图（每个视频只有一个挂品） |

### 文本信息

| 字段 | 说明 |
|------|------|
| ASR | 视频语音转文本（EU地区为外语） |
| OCR | 视频画面中识别出的文字（EU地区为外语） |
| product_category | 挂车商品的英文三级类目名称 |

### 外部数据打标（权威数据，必须完全信任）

| 字段 | 说明 |
|------|------|
| `is_aigc` | AIGC 判定字段 |

**AIGC 判断逻辑**：
- `is_aigc` 为 `null` → 非AIGC内容，跳过
- `is_aigc` 有值（数字）→ AIGC内容，进入分析

---

## 判定流程

```
Step 1: 检查 is_aigc 字段
    ├─ 为 null → 跳过（skipped）
    └─ 有值（数字）→ 进入 Step 2

Step 2: 检查是否有商品推广（ASR/OCR）
    ├─ 无推广 → 不命中（no_hit）
    └─ 有推广 → 进入 Step 3

Step 3: 商品对比（视频帧商品 vs 挂车商品主图）
    ├─ 商品外观一致 → 不命中（no_hit）
    └─ 商品外观不一致 → 进入 Step 4

Step 4: 豁免检查
    ├─ 挂车商品属于盲盒/首饰/玉石/卡牌类目？
    │   └─ 是 → 检查视频帧商品与挂车商品是否同三级类目
    │       ├─ 同三级类目 → 豁免（no_hit）
    │       └─ 不同三级类目 → 命中（hit）
    ├─ 挂车商品属于服饰（上下装，不含鞋帽）类目？
    │   └─ 是 → 检查是否为同SPU不同SKU（仅颜色/花纹差异）
    │       ├─ 是 → 豁免（no_hit）
    │       └─ 否 → 命中（hit）
    └─ 其他类目 → 命中（hit）
```

---

## 推广判定标准

ASR 或 OCR 中存在以下任意一种情况，即视为"有商品推广"：

| 推广类型 | 说明 | 英文关键词示例 |
|----------|------|---------------|
| 购买引导 | 引导用户点击购物车、下单、购买 | buy now, order now, shop now, add to cart, click cart, purchase |
| 价格信息 | 提及商品价格、优惠 | price, $, €, £, cost, only, just, special price |
| 促销信息 | 提及促销活动 | discount, sale, promotion, limited time, special offer, buy one get one |
| 商品介绍 | 介绍商品功能、特点 | this product, it has, features, made of, material |

**判定逻辑**：ASR 或 OCR 中存在上述任意类型内容 → 视为有推广

---

## 商品一致性判定标准

### 一致（不命中）

视频帧中出现的商品与挂车商品主图在以下方面一致：
- 商品类型（如都是口红、都是T恤）
- 商品款式、形状
- 商品颜色、花纹（服饰类除外，见豁免规则）
- 商品材质外观

### 不一致（命中，除非豁免）

视频帧中出现的商品与挂车商品主图存在明显差异：
- 完全不同的商品类型（如挂车是口红，视频展示的是眼影）
- 同款但不同款式（如挂车是圆领T恤，视频展示的是V领T恤）
- 明显不同的设计元素

---

## 豁免规则

### 豁免类型 1：盲盒、首饰、玉石、卡牌
### Exemption Type 1: Blind Boxes, Jewelry, Jade, Collectible Cards

**条件**：挂车商品的 `product_category`（英文）语义上属于以下类目类型之一：

| 类目类型 | 英文关键词/类目名示例 |
|----------|----------------------|
| 盲盒 | Blind Boxes, Mystery Boxes, Surprise Boxes |
| 首饰 | Jewelry, Fashion Accessories, Costume Jewelry & Accessories, Charms & Pendants, Necklaces, Earrings, Bracelets, Rings |
| 玉石 | Jade, Gemstones, Precious Stones, Crystals |
| 卡牌 | Collectible Cards, Trading Cards, Game Cards, Sports Cards |

**豁免规则**：
- 视频帧中展示的商品与挂车商品属于**同一个三级类目** → 豁免（不命中）
- 视频帧中展示的商品与挂车商品**不属于同一个三级类目** → 命中

**示例**：
- 挂车是 "Blind Boxes"，视频展示的是同系列另一个盲盒款式 → 豁免（同三级类目）
- 挂车是 "Necklaces"，视频展示的是 "Rings" → 需判断是否同三级类目（不同则命中）

---

### 豁免类型 2：服饰（上下装，不含鞋帽）
### Exemption Type 2: Apparel (Tops & Bottoms, excluding Shoes & Hats)

**条件**：挂车商品的 `product_category`（英文）语义上属于服饰类（上下装）

| 类目类型 | 英文关键词/类目名示例 |
|----------|----------------------|
| 上衣 | T-Shirts, Shirts, Tops, Blouses, Sweaters, Hoodies, Jackets, Coats |
| 下装 | Pants, Trousers, Jeans, Shorts, Skirts, Dresses, Leggings |

**注意**：以下类目**不适用**此豁免：
- Shoes, Footwear, Sneakers（鞋类）
- Hats, Caps, Headwear（帽类）
- Bags, Handbags（包类）
- Accessories（配饰，除首饰外）

**豁免规则**：
- 视频帧中展示的商品与挂车商品是**同SPU不同SKU**（仅颜色/花纹差异）→ 豁免（不命中）
- 视频帧中展示的商品与挂车商品**款式/形状不同** → 命中

**判断标准**：

| 情况 | 结果 | 说明 |
|------|------|------|
| 同款不同颜色 | 豁免 | 同SPU不同SKU |
| 同款不同花纹 | 豁免 | 同SPU不同SKU |
| 不同款式（如圆领 vs V领） | 命中 | 不是同SPU |
| 不同类型（如T恤 vs 衬衫） | 命中 | 完全不同商品 |

---

## 判定逻辑总结

| 情况 | 结果 | 说明 |
|------|------|------|
| is_aigc = null | skipped | 非AIGC内容，不适用此规则 |
| AIGC + 无商品推广 | no_hit | 没有推广行为，不构成货不对板 |
| AIGC + 有推广 + 商品一致 | no_hit | 展示商品与挂车商品一致 |
| AIGC + 有推广 + 商品不一致 + 盲盒/首饰/玉石/卡牌 + 同三级类目 | no_hit（豁免） | 特殊类目豁免 |
| AIGC + 有推广 + 商品不一致 + 服饰 + 同SPU不同SKU | no_hit（豁免） | 服饰类目豁免 |
| AIGC + 有推广 + 商品不一致 + 无豁免 | hit | 货不对板 |

---

## 输出格式

结构化JSON输出：

```json
{
  "decision": "hit|no_hit|skipped",
  "inconsistency_type": "appearance|category|null",
  "exemption_check": {
    "category_type": "normal|blind_box|jewelry|jade|card|apparel",
    "is_exempted": true|false,
    "exemption_reason": "Same L3 category exemption|Same SPU different SKU exemption|null"
  },
  "reason": "判定理由（英文）",
  "frames_analyzed": [1, 2, 3, 4, 5],
  "frames_with_product": [2, 3, 4]
}
```

### 字段说明

| 字段 | 说明 |
|------|------|
| decision | 判定结果：hit=命中；no_hit=不命中；skipped=跳过（非AIGC） |
| inconsistency_type | 不一致类型：appearance=外观不一致；category=类目不一致；null=一致 |
| exemption_check.category_type | 挂车商品类目类型：normal=普通；blind_box=盲盒；jewelry=首饰；jade=玉石；card=卡牌；apparel=服饰 |
| exemption_check.is_exempted | 是否豁免：true=豁免；false=不豁免 |
| exemption_check.exemption_reason | 豁免理由（英文） |
| reason | 判定理由说明（英文） |
| frames_analyzed | 分析过的视频帧编号（全部5帧） |
| frames_with_product | 出现商品展示的视频帧编号 |

## 判定示例

### 示例 1：跳过（非AIGC）

**输入**：
- is_aigc: null
- product_category: "T-Shirts"

**判定**：skipped
**理由**：is_aigc is null, non-AIGC content, rule not applicable

---

### 示例 2：不命中（无推广）

**输入**：
- is_aigc: 12345
- ASR: "Hello everyone, welcome to my channel"
- OCR: （为空）
- product_category: "T-Shirts"

**判定**：no_hit
**理由**：No product promotion detected in ASR/OCR

---

### 示例 3：不命中（商品一致）

**输入**：
- is_aigc: 12345
- ASR: "Buy now! This t-shirt is made of cotton"
- 视频帧商品：红色圆领T恤
- 挂车商品主图：红色圆领T恤
- product_category: "T-Shirts"

**判定**：no_hit
**理由**：Product in video frames matches the bound product main image

---

### 示例 4：命中（普通类目，商品不一致）

**输入**：
- is_aigc: 12345
- ASR: "Click cart to purchase! Only $19.99"
- 视频帧商品：口红
- 挂车商品主图：眼影盘
- product_category: "Eyeshadow"

**判定**：hit
**inconsistency_type**: category
**理由**：Video shows lipstick but bound product is eyeshadow palette - completely different product types

---

### 示例 5：豁免（盲盒同三级类目）

**输入**：
- is_aigc: 12345
- ASR: "Limited time offer! Buy these mystery boxes"
- 视频帧商品：盲盒款式A
- 挂车商品主图：盲盒款式B（同系列）
- product_category: "Blind Boxes"

**判定**：no_hit
**exemption_check**:
  - category_type: blind_box
  - is_exempted: true
  - exemption_reason: "Same L3 category exemption"
**理由**：Both are Blind Boxes - same L3 category exemption applies

---

### 示例 6：命中（首饰不同三级类目）

**输入**：
- is_aigc: 12345
- ASR: "Shop now! Beautiful jewelry pieces"
- 视频帧商品：戒指
- 挂车商品主图：项链
- product_category: "Necklaces"

**判定**：hit
**inconsistency_type**: category
**exemption_check**:
  - category_type: jewelry
  - is_exempted: false
  - exemption_reason: null
**理由**：Video shows rings but bound product is necklaces - different L3 categories within jewelry

---

### 示例 7：豁免（服饰同SPU不同SKU）

**输入**：
- is_aigc: 12345
- ASR: "Buy this t-shirt! Only $15"
- 视频帧商品：蓝色圆领T恤
- 挂车商品主图：红色圆领T恤
- product_category: "T-Shirts"

**判定**：no_hit
**exemption_check**:
  - category_type: apparel
  - is_exempted: true
  - exemption_reason: "Same SPU different SKU exemption"
**理由**：Same style (crew neck t-shirt), only color differs - same SPU different SKU exemption applies

---

### 示例 8：命中（服饰不同款式）

**输入**：
- is_aigc: 12345
- ASR: "Discount! Limited stock!"
- 视频帧商品：V领T恤
- 挂车商品主图：圆领T恤
- product_category: "T-Shirts"

**判定**：hit
**inconsistency_type**: appearance
**exemption_check**:
  - category_type: apparel
  - is_exempted: false
  - exemption_reason: null
**理由**：Different neckline styles (V-neck vs crew neck) - not same SPU
