# IPP Chief Judge Rules
# 货不对板首席裁判裁决规则

## 版本信息

- 当前版本：2026-05-26-v2
- 上次更新：2026-05-26
- 更新内容：移除 skipped 逻辑，支持 AIGC 和非AIGC 内容

---

## 裁决原则

### 1. 多数票原则

- **2位或3位专家意见一致** → 采纳多数意见
- **3位专家意见各不相同** → 进行深度分析，选择最有说服力的理由

### 2. 豁免判定的一致性

- 对于豁免规则的应用，需要检查专家们对 `category_type` 的判断是否一致
- 如果专家们对 `category_type` 判断不同（如一个认为是 `apparel`，另一个认为是 `normal`），需要根据 `product_category` 字段重新评估

### 3. 不一致类型的汇总

| 情况 | 最终 inconsistency_type |
|------|------------------------|
| 多数专家认为 `appearance` | `appearance` |
| 多数专家认为 `category` | `category` |
| 一致或无不一致 | `null` |

---

## 裁决流程

```
收到3位专家的评审结果
    ↓
统计 decision 投票
    ├─ 2-3票 hit → 最终 hit
    ├─ 2-3票 no_hit → 最终 no_hit
    └─ 1-1-1 分散 → 深度分析理由
    ↓
汇总 exemption_check
    ├─ 多数专家豁免 → 最终豁免
    └─ 多数专家不豁免 → 最终不豁免
    ↓
生成最终裁决理由（综合各专家理由）
```

---

## confidence 计算

| 专家一致性 | confidence |
|-----------|------------|
| 3票一致 | 1.0 |
| 2票一致，1票不同 | 0.7 |
| 3票各不相同 | 0.4 |

## 裁决示例

### 示例 1：3票一致命中

**专家投票**：
- Expert 1: hit
- Expert 2: hit
- Expert 3: hit

**最终裁决**：
```json
{
  "final_decision": "hit",
  "inconsistency_type": "category",
  "exemption_check": {
    "category_type": "normal",
    "is_exempted": false,
    "exemption_reason": null
  },
  "final_reason": "All 3 experts agree: Video shows lipstick but bound product is eyeshadow palette - completely different product categories. No exemption applies.",
  "expert_votes": {
    "expert_1": "hit",
    "expert_2": "hit",
    "expert_3": "hit"
  },
  "confidence": 1.0,
  "frames_with_product": [1, 2, 3, 4, 5]
}
```

---

### 示例 2：2票豁免，1票命中

**专家投票**：
- Expert 1: no_hit (exempted - same SPU different SKU)
- Expert 2: no_hit (exempted - same SPU different SKU)
- Expert 3: hit

**最终裁决**：
```json
{
  "final_decision": "no_hit",
  "inconsistency_type": null,
  "exemption_check": {
    "category_type": "apparel",
    "is_exempted": true,
    "exemption_reason": "Same SPU different SKU exemption"
  },
  "final_reason": "2 out of 3 experts agree: Same t-shirt style (crew neck), only color differs. Apparel exemption for same SPU different SKU applies.",
  "expert_votes": {
    "expert_1": "no_hit",
    "expert_2": "no_hit",
    "expert_3": "hit"
  },
  "confidence": 0.7,
  "frames_with_product": [2, 3, 4]
}
```
