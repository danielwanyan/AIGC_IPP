# AIGC IPP Reviewer User Prompt

## 重要提醒（请务必遵守）

- **必须查看全部5张视频帧**（{{All_images}} 中前5张），不能只看部分
- **对比视频帧中展示的商品 vs 挂车商品全量图片**（{{All_images}} 中第6张及以后，任意一张一致即算一致）
- **product_category 仅用于豁免判断**，不得用于判断视频帧中的商品类型
- **禁止幻觉**：只能描述图片中实际存在的内容，不能猜测
- **aigc_video_id 决定 issue_type**：有值→AIGC_IPP，null→non-AIGC_IPP，所有内容都要分析，不会跳过
- **严格遵守防误判规则**（FP-01至FP-11），避免误伤

### 常见误判场景提醒：
✓ 光线/色差差异不算不一致（影棚 vs 自然光）
✓ 品牌名称/OCR文字不对比（包括镜像文字）
✓ 设计效果图 vs 实物的视觉效果差异不算
✓ 服饰穿着方式差异不算（裤子塞靴子、袖子挽起等）
✓ 视频中同时展示多个商品但挂车商品也出现了 → 不命中
✓ **FP-04 特别注意**：必须对比所有挂车商品图片（第6张及以后），不能只看第一张主图。只要与任意一张一致就算一致（no_hit）。只对比给定的全量商品图片，不假设其他变体存在（FP-04）
✓ **纯颜色差异不算不一致（功能款式结构完全一致，全类目适用，FP-08）**
✓ **视频帧中的小物件/装饰品不算（只对比商品本身，FP-09）**
✓ **product_category 元数据与图片不一致不算（仅用于豁免判断，FP-10）**
✓ **有讲品但商品未物理出镜不算 IPP（FP-11）**：仅屏幕/截图/口头提及，无实物展示 → no_hit。⚠️ 必须有图片才能判断，无图片时不能套用 FP-11
✓ **issue_type 必须严格匹配 aigc_video_id**：有值→AIGC_IPP，null→non-AIGC_IPP

## 输入信息

### 外部数据打标（权威数据，必须完全信任）

| 字段 | 说明 |
|------|------|
| {{aigc_video_id}} | 外部权威AIGC判定字段：null=非AIGC；数字=AIGC。**所有内容都需要分析，不会跳过** |

### 文本信息

| 字段 | 说明 |
|------|------|
| {{ASR}} | 视频语音转文本（EU地区为外语） |
| {{OCR}} | 视频画面中识别出的文字（EU地区为外语） |
| {{product_category}} | 挂车商品的三级类目名称（可能是任何语言，仅用于豁免判断） |

### 视觉理解输入

| 字段 | 说明 |
|------|------|
| {{All_images}} | 所有图片（前5张=视频帧，第6张及以后=挂车商品全量图片） |

### All_images 重要说明

- `{{All_images}}` 是**图片数组**，包含所有需要分析的图片
- **图片顺序固定**：
  - 第 1-5 张：视频帧图片（基于视频时长等分抓取的关键帧）
  - 第 6 张及以后：挂车商品全量图片（主图、细节图、不同颜色/款式图等）
- **商品一致性判断规则**：
  - 对比视频帧（第1-5张）中的商品 vs 挂车商品图片（第6张及以后）
  - 只要视频帧中的商品与**任意一张**挂车商品图片在视觉上一致 → 判定为一致（no_hit）
  - 只有当视频帧中的商品与**所有**挂车商品图片都不一致时 → 才进入豁免检查

## 任务

请根据 System Prompt 中的规则，分析上述输入信息，判断是否存在"货不对板"问题。

## 要求

1. 必须查看全部5张视频帧（{{All_images}} 中前5张）
2. 对比视频帧中展示的商品 vs 挂车商品全量图片（{{All_images}} 中第6张及以后，任意一张一致即算一致）
3. 严格按照 System Prompt 中的判定流程执行
4. 严格遵守防误判规则（FP-01至FP-11）
   - **特别注意 FP-10**：product_category 仅用于豁免判断，商品一致性必须以图片对比为准，绝对不能因为 category 与图片不一致就判定为 IPP
   - **特别注意 FP-11**：有讲品但商品未物理出镜（仅屏幕/截图/口头）→ no_hit，必须先检查商品是否物理展示再进行对比。⚠️ 前置条件：必须先确认 `{{All_images}}` 包含视频帧和商品图片。如果图片缺失，不得应用 FP-11。
   - **特别注意 FP-04**：必须逐一对比所有挂车商品图片（第6张及以后），不能只对比第一张主图。在 `matched_product_image_indices` 字段中记录匹配成功的图片索引，在 `compared_product_image_count` 字段中记录对比的图片总数。
5. 判定理由中必须引用适用的防误判规则编号（如 FP-01）
6. 输出严格的 JSON 格式
7. **issue_type 必须严格根据 `{{aigc_video_id}}` 设置**：有值→AIGC_IPP，null→non-AIGC_IPP
