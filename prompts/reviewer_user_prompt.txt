# AIGC IPP Reviewer User Prompt

## 重要提醒（请务必遵守）

• **必须查看全部5张视频帧**（URL_Frames），不能只看部分
• **对比视频帧中展示的商品 vs 挂车商品主图**（Product_image）
• **product_category 仅用于豁免判断**，不得用于判断视频帧中的商品类型
• **禁止幻觉**：只能描述图片中实际存在的内容，不能猜测
• **aigc_video_id 只是标签**，所有内容都要分析，不会跳过
• **严格遵守防误判规则**（FP-01至FP-07），避免误伤

### 常见误判场景提醒：
✓ 光线/色差差异不算不一致（影棚 vs 自然光）
✓ 品牌名称/OCR文字不对比（包括镜像文字）
✓ 设计效果图 vs 实物的视觉效果差异不算
✓ 服饰穿着方式差异不算（裤子塞靴子、袖子挽起等）
✓ 视频中同时展示多个商品但挂车商品也出现了 → 不命中
✓ 只对比给定的商品主图，不假设其他变体存在
✓ **纯颜色差异不算不一致（功能款式结构完全一致，全类目适用，FP-08）**
✓ **视频帧中的小物件/装饰品不算（只对比商品本身，FP-09）**

## 输入信息

### 外部数据打标（权威数据，必须完全信任）

| 字段 | 说明 |
|------|------|
| aigc_video_id | 外部权威AIGC判定字段：null=非AIGC；数字=AIGC。**所有内容都需要分析，不会跳过** |

### 文本信息

| 字段 | 说明 |
|------|------|
| ASR | 视频语音转文本（EU地区为外语） |
| OCR | 视频画面中识别出的文字（EU地区为外语） |
| product_category | 挂车商品的三级类目名称（可能是任何语言，仅用于豁免判断） |

### 视觉理解输入

| 字段 | 说明 |
|------|------|
| URL_Frames | 视频帧图片URL（5张，基于视频时长等分抓取的关键帧） |
| Product_image | 挂车商品主图URL（每个视频只有一个挂品） |

## 任务

请根据 System Prompt 中的规则，分析上述输入信息，判断是否存在"货不对板"问题。

## 要求

1. 必须查看全部5张视频帧（URL_Frames）
2. 对比视频帧中展示的商品 vs 挂车商品主图（Product_image）
3. 严格按照 System Prompt 中的判定流程执行
4. 严格遵守防误判规则（FP-01至FP-07）
5. 判定理由中必须引用适用的防误判规则编号（如 FP-01）
6. 输出严格的 JSON 格式
