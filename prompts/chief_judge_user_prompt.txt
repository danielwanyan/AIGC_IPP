# AIGC IPP Chief Judge User Prompt

## 重要提醒

• **重点审查防误判规则（FP-01至FP-11）的应用情况**
• **特别关注 FP-04（全量图片对比）、FP-08（纯颜色差异豁免）、FP-09（小物件/装饰品忽略）、FP-10（product_category 仅用于豁免判断）和 FP-11（商品未物理出镜豁免）的正确应用**
• **issue_type 必须严格匹配 aigc_video_id**：有值→AIGC_IPP，null→non-AIGC_IPP，如专家判定错误必须纠正
• **FP-10 重中之重**：绝对不能因为 `product_category` 元数据与图片不一致就判定为 IPP，商品一致性必须以图片对比为准。如果专家因为 category 标注错误而判定 hit，必须纠正为 no_hit。
• **FP-11 重中之重**：有讲品但商品未以实物形式物理展示（仅屏幕/截图/口头）不算 IPP。如果专家错误地判定为 hit，必须纠正为 no_hit。⚠️ 注意：FP-11 仅适用于有图片但视频中无实物展示的场景。如专家因缺少图片而套用 FP-11，必须纠正。
• **FP-04 重中之重**：必须检查专家是否对比了**所有**挂车商品图片（第6张及以后），不能只对比第一张主图。检查专家的 `matched_product_image_indices` 和 `compared_product_image_count` 字段是否正确填写。如果专家错误地只对比了单张图片而忽略了其他图片，必须纠正其判定。如果专家声称"所有图片都不一致"但 `matched_product_image_indices` 为空且 `compared_product_image_count` 不等于实际图片总数，属于 FP-04 违规，必须纠正。
• **全量图片对比规则审查**：注意审查专家是否正确应用了"任意一张商品图片一致即算一致"的规则，如果专家错误地只对比了单张主图而忽略了其他图片，需要纠正其判定
• 如果专家没有正确应用防误判规则导致误伤，请在最终裁决中纠正
• 输出必须包含：中文裁决摘要 + 专家详情表 + 裁决详情表 + 中文裁决依据 + JSON
• 便于人工审核是首要目标

### 全量图片对比规则说明（重要！）

**注意：本节点不直接接收商品图片，仅审查专家是否正确应用了以下规则：**

- 商品图片为 **JSON 数组字符串格式**，包含多张图片（主图、细节图、不同颜色/款式图等）
- **商品一致性判断规则**：只要视频帧中的商品与**任意一张**商品图片在视觉上一致 → 判定为一致（no_hit）
- 只有当视频帧中的商品与**所有**商品图片都不一致时 → 才进入豁免检查
- **审查重点**：检查专家的判定理由中是否正确考虑了"全量图片对比"，如果专家错误地只对比了单张图片而忽略了其他图片，需要纠正其判定
- **FP-04 专项检查要点**：
  1. 每位专家的 `compared_product_image_count` 是否等于实际商品图片总数
  2. 每位专家的 `matched_product_image_indices` 是否合理（如果有匹配，索引是否有效）
  3. 如果专家判定为 hit，是否明确说明了"与所有 N 张图片都不一致"
  4. 如果专家判定为 no_hit，是否明确说明了匹配的图片索引
  5. 任何专家未正确填写这两个字段都属于 FP-04 违规，需要纠正

## 任务

请根据 System Prompt 中的裁决规则，汇总3位专家的评审意见，做出最终裁决。

## 要求

1. 综合分析3位专家的意见
2. 重点审查防误判规则的应用情况，必要时纠正专家的误判
3. 按照多数票原则进行裁决（防误判规则优先）
4. 检查豁免判定的一致性
5. 按照指定格式输出：中文摘要 → 专家详情表 → 裁决详情表 → 中文裁决依据 → JSON
6. 确保输出清晰、详细，便于人工审核
